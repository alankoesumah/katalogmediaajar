Integrasi Database Google Sheets

Aplikasi ini dapat terhubung secara Sinkronisasi Otomatis Real-Time ke Google Sheet milik Anda. Seluruh perubahan data nama media, foto, dan lokasi penyimpanan akan langsung tersimpan di Google Sheets, dan otomatis diperbarui ke semua perangkat setiap 15 detik.

Cara Menghubungkan Sheet Anda (3 Langkah Mudah):

  1. Buka spreadsheet Anda (tombol "Buka Sheet" di atas), lalu pastikan baris ke-1 berisi kolom header berikut:
    id | nama_media | foto | lokasi_penyimpanan | jumlah | status | peminjam | tgl_pinjam
  2. Buka menu Ekstensi > Apps Script di Google Sheet Anda, hapus kode lama, tempelkan (paste) kode skrip di bawah ini, lalu klik Simpan (ikon disket).
  3. Klik tombol Deploy > Deployment Baru (New Deployment), pilih tipe Web App, atur "Who has access" menjadi "Anyone" (Siapa Saja), lalu salin Web App URL dan tempel ke kolom input di atas!

Setiap kali Anda mengubah kode skrip, Anda harus membuat Deployment Baru lagi (atau edit deployment lama) agar perubahan berlaku pada Web App URL yang sudah dipakai. 

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  if (data.length <= 1) return ContentService.createTextOutput(JSON.stringify([])).setMimeType(ContentService.MimeType.JSON);
  var headers = data[0];
  var result = [];
  for (var i = 1; i < data.length; i++) {
    var obj = {};
    for (var j = 0; j < headers.length; j++) {
      obj[headers[j]] = data[i][j];
    }
    result.push(obj);
  }
  return ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var postData = JSON.parse(e.postData.contents);
  
  if (postData.action === 'save_all') {
    sheet.clear();
    sheet.appendRow(['id', 'nama_media', 'foto', 'lokasi_penyimpanan', 'jumlah', 'status', 'peminjam', 'tgl_pinjam']);
    postData.items.forEach(function(item) {
      sheet.appendRow([item.id, item.nama_media, item.foto, item.lokasi_penyimpanan, item.jumlah, item.status, item.peminjam || '', item.tgl_pinjam || '']);
    });
    return ContentService.createTextOutput(JSON.stringify({status: 'success'})).setMimeType(ContentService.MimeType.JSON);
  }
}

Penyimpanan Foto di Cloudinary

Belum Diatur

Agar foto media dapat tampil realtime di semua perangkat (bukan hanya di HP/laptop tempat foto diunggah), foto perlu disimpan di Cloudinary lalu hanya link URL-nya yang dikirim ke Google Sheet.

Cara mendapatkan Cloud Name & Upload Preset:

  1. Daftar/masuk gratis di cloudinary.com, lalu buka Dashboard — salin nilai Cloud Name.
  2. Buka menu Settings > Upload, scroll ke Upload presets, klik Add upload preset.
  3. Ubah Signing Mode menjadi Unsigned, simpan, lalu salin nama presetnya ke kolom di atas.
